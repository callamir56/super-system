# پژوهش: کاربرد هوش مصنوعی در بیماری‌های قلبی

پژوهش علمی دانش‌آموزی (پایه دهم تجربی) درباره کاربرد هوش مصنوعی در تشخیص، پیش‌بینی و
پیشگیری بیماری‌های قلبی — ۷ فصل، ۶ شکل، ۹ جدول، فهرست مطالب خودکار و منابع ارجاع‌دار.

## فایل اصلی

- `پژوهش_قلب_و_هوش_مصنوعی_ویرایش_کامل.docx` — نسخه بازنویسی‌شده و گسترش‌یافته (A4، راست‌به‌چپ)
- `پژوهش_قلب_و_هوش_مصنوعی_۵۰_صفحه.docx` — نسخه اولیه (بدون تغییر)

## ساخت مجدد فایل

```bash
pip install python-docx matplotlib arabic-reshaper python-bidi
python3 src/figures.py       # ساخت شکل‌ها در assets/figures
python3 src/build_docx.py    # ساخت فایل Word از محتوای src/content
```

- `src/content/` متن فصل‌ها به‌صورت داده ساختاریافته
- `src/figures.py` تولید شکل‌ها با برچسب فارسی
- `src/build_docx.py` قالب‌بندی سند (استایل‌ها، جدول‌ها، فهرست، شماره صفحه)
- `src/normalize_docx.py` اصلاح ترتیب عناصر XML مطابق اسکیمای OOXML

## نکته

فهرست مطالب با فیلد خودکار Word ساخته شده است؛ اگر شماره صفحه‌ها به‌روز نبود،
`Ctrl+A` سپس `F9` → «Update entire table».
